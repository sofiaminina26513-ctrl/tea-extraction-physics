# Физика экстракции вкусоароматических веществ чая

Репозиторий содержит экспериментальные данные, скрипты для математического анализа и моделирования процессов экстракции чая спектрофотометрическим методом. Проект разработан для очного тура конкурса «Ученые будущего».

## 🔬 Краткое описание проекта
Цель работы — перевод органолептической оценки истощения чайного сырья на язык строгих физических величин. С помощью самодельного спектрофотометра (на базе лазера 650 нм и фотодиода) исследована кинетика заваривания 7 марок чая и определены границы применимости модели геометрической прогрессии. На основе статистического анализа выборки из 30 человек рассчитан объективный биологический порог вкусовой чувствительности к танинам ($c_{\text{crit}} = 0.182$).

## 📊 Описание структуры файлов в репозитории

### 🐍 Скрипты на Python:
* `График c(t).py` — Моделирование кинетики экстракции. Расчет констант времени для процессов поверхностной десорбции ($\tau_1 \approx 19$ с) и внутрипоровой диффузии ($\tau_2 \approx 136$ с).
* `Критические кружки.py` — Анализ математического предела истощения пакетика (расчет кривых истощения по закону геометрической прогрессии до пересечения с порогом вкуса).
* `Обработка предела чувствительности.py` — Статистическая обработка результатов экспериментов на людях (30 респондентов), построение распределения Гаусса и вычисление критической концентрации $c_{\text{crit}} = 0.182%.

### 📈 Таблицы с данными (Excel):
* `Таблица значений.xlsx` — Основной массив спектрофотометрических измерений фототока (мкА) для 7 марок чая на протяжении 13 последовательных заварок (всего 91 контрольная точка) и результаты анкетирования респондентов.
* `Дополнительные значения.xlsx` — Дополнительные протоколы калибровки, замеры аномалий.

## 🎯 Основные результаты
1. **Подтверждение модели:** Экстракция чая со 2-й по 13-ю заварку строго следует закону геометрической прогрессии ($R^2 > 0.96$).
2. **Порог вкуса:** Математически зафиксирован предел рецепторов человека ($c_{\text{crit}} = 0.182$).
3. **Рейтинг стойкости:** Гранулированный чай (технология CTC, марка Kenika) выдерживает рекордные 47 заварок до падения ниже вкусового порога.
